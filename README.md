## ✨ Overview
 
LED Sign Board turns any phone into a glowing dot-matrix sign. Type a message, pick an effect and a colour, then go full screen. It is built as one `index.html` file, so it loads instantly and is easy to host anywhere.
 
## 🎛️ Features
 
| | Feature | Details |
|---|---|---|
| 🔴 | **Dot-matrix display** | Authentic LED look with softly glowing dots |
| 🎞️ | **Four effects** | Scroll left, scroll right, still, blink |
| 🎚️ | **Fine control** | Adjustable scroll speed, text size and dot size |
| 🎨 | **Colour** | Six presets plus a custom colour picker |
| 📺 | **Full screen** | Controls fade after 3 seconds; tap the screen to bring them back |
| 🔄 | **Sideways mode** | Turn the sign landscape while holding the phone upright |
| 🪞 | **Mirror text** | Flip the message for reflections and windows |
| 🔆 | **Stays awake** | Keeps the screen on while the sign is showing |
| 💾 | **Remembers you** | Settings are saved on your device |
 
## 🚀 Quick Start
 
1. Open **[ath1t.github.io/led-signboard](https://ath1t.github.io/led-signboard/)** in your phone's browser.
2. Tap **Edit** and type your message.
3. Choose an effect, colour and sizes.
4. Tap **Show sign**.
5. Tap **Full screen**. Tap anywhere to bring the buttons back.
> [!TIP]
> **iPhone:** Safari does not support full screen for web pages. Tap **Share → Add to Home Screen**, then open the sign from the new icon to hide the browser bars.
 
## 🌐 Host Your Own
 
<details>
<summary><b>Deploy to GitHub Pages in four steps</b></summary>
<br>
1. On GitHub, create a new **public** repository.
2. Upload `index.html` (and this `README.md`) and commit.
3. Go to **Settings → Pages**. Under *Build and deployment*, set Source to **Deploy from a branch**, choose `main` and `/ (root)`, then click **Save**.
4. Wait a few minutes (it can take up to about 10). Your site will be live at:
```
https://<username>.github.io/<repo-name>/
```
 
If the site does not publish, add an empty file named `.nojekyll` to the repo root.
 
</details>
## 📝 Notes
 
- If a message looks cramped, lower **Text size** or **Dot size**.
- Everything runs locally in your browser. Nothing is sent anywhere.
